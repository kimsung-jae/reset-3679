## 회차 감시 수정
기존처럼 추첨 경계에 몇 번만 확인하고 쉬지 않습니다.
백그라운드에서 계속 API를 확인합니다. 경계 전후에는 8초, 평소에는 25초 간격으로 확인하고 새 회차가 발견되면 즉시 채점·리셋주기 진행·다음 추천을 저장합니다.

화면에 API 최신 날짜/회차와 마지막 새회차 감지 시각을 표시해, 앱 문제인지 API가 아직 안 넘어온 것인지 바로 구분할 수 있습니다.
