# 보글사다리3 V4.3.2 Reset Lab

동일한 실제 회차에서 5개 엔진을 동시에 실전 비교합니다.

- 무리셋 기준엔진
- 3회마다 분석 history Soft Reset
- 4회마다 분석 history Soft Reset
- 6회마다 분석 history Soft Reset
- 7회마다 분석 history Soft Reset

Soft Reset은 승/패 기록을 지우지 않습니다. 해당 엔진의 분석용 history만 그 시점 API가 반환한 최신 스냅샷으로 교체합니다.
그 사이 회차는 기존 history와 새 스냅샷을 병합합니다. 따라서 수동으로 '기록 초기화 후 재조회'했을 때 생기던 입력 데이터 변화만 가상으로 재현합니다.

모든 엔진의 분석법은 동일합니다: 좌/우, 3/4줄, 홀/짝 개별 + 최근3~6 완전패턴 + 가중치 없음 + 최대 최근480 사용.

화면에는 엔진별 누적 실전승률, 최근20, 누적손익, 현재 제외값, 분석데이터 개수, 리셋 횟수와 주기 진행상태가 표시됩니다.
